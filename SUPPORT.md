# Support

Use the repository's issue form when a documented command, test, chart, or KPI
cannot be reproduced. Include your operating system, Python version, exact
command, input format, and a minimal error excerpt.

Questions about the included public-domain workbook and its fields should start
with [DATASET.md](DATASET.md). Do not attach credentials, private business
records, or an unpatched vulnerability to a public issue; use
[SECURITY.md](SECURITY.md) for sensitive reports.
